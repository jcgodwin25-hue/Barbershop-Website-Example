# Vintage Barbershop Website 💈

A modern, responsive website for a traditional barbershop, designed to showcase services, pricing, business hours, and the overall customer experience.

## 📌 Project Overview

The Vintage Barbershop Website is a front-end web development project built to establish a professional online presence for a local barbershop. The website provides customers with essential business information through a clean, user-friendly interface inspired by classic barbershop aesthetics.

This project demonstrates foundational skills in **HTML5, CSS3, and JavaScript**, including webpage structure, responsive styling, and interactive functionality.

## ✨ Features

- **Responsive Design:** Designed to provide a user-friendly experience across desktop, tablet, and mobile devices.
- **Services & Pricing:** Displays available barbering services and their prices.
- **Business Hours:** Clearly communicates the shop's operating schedule.
- **Classic Visual Identity:** Combines traditional barbershop aesthetics with a clean, modern layout.
- **Interactive Elements:** Uses JavaScript to support dynamic behavior and user interactions.
- **Customer-Focused Layout:** Organizes information so visitors can quickly find the services and details they need.

## 🛠️ Technologies Used

- **HTML5** — Structures the webpage and its content.
- **CSS3** — Provides styling, layout, colors, and responsive design.
- **JavaScript** — Adds interactive functionality and dynamic behavior.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A modern web browser.
- A code editor, such as Visual Studio Code.
- Git, if you want to clone the repository.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Open the project in Visual Studio Code.

4. Open `index.html` in your browser, or use the **Live Server** extension for a convenient local development experience.

> Replace `YOUR_REPOSITORY_URL` and `YOUR_PROJECT_FOLDER` with your actual repository URL and folder name.
